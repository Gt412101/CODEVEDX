## 📌 Project Overview

This project presents a modern and user-friendly **Mobile App Signup Flow** designed in **Figma**. The design focuses on creating a simple, secure, and visually appealing onboarding experience that allows users to register quickly with minimal effort.

---

## 🎯 Objective

- Create an easy-to-use signup experience.
- Reduce user effort during registration.
- Maintain a clean and modern interface.
- Improve usability and accessibility.

---

## 🛠 Tool Used

- Figma

---

## ✨ Features

- Welcome Screen
- Sign Up Screen
- Login Screen
- Email & Password Input
- Password Visibility Toggle
- Clean UI Design
- Modern Typography
- Responsive Mobile Layout
- User-Friendly Navigation

## 🎨 Design Principles

- Minimal Design
